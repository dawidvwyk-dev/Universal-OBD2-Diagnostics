# Rogue OBD2 Diagnostic Tool

A professional OBD2/EOBD diagnostic application for **Windows 10/11** and **Android**, built with Flutter on a shared codebase. iOS is out of scope.

The architecture and plan are in the [stack and architecture proposal](https://claude.ai/artifact/51gpXxKBJ2ij9yGYgZz8KK).

## Repository layout

```
packages/
  obd_decoders    Pure decoders: DTC, PIDs, VIN, readiness, units
  obd_protocols   ELM response parser, ISO-TP, protocol list, request validation
  obd_transport   Transport interface, TCP (Wi-Fi), in-memory
  obd_engine      ElmLink, adapter probe, ObdSession, SafetyGate, comm log
  obd_sim         Simulated adapter + vehicles (TEST USE ONLY)
  diag_store      Encrypted database (drift), repository API
app/              Flutter app (Windows + Android)
docs/screenshots  UI screenshots generated by the widget tests
```

The engine packages are pure Dart and do not depend on Flutter.

## Building

Requires Flutter 3.50.1 (Dart 3.14).

```sh
flutter pub get                      # resolves the whole workspace
cd packages/obd_engine && dart test  # engine tests against the simulator
cd app && flutter test               # app flow tests
cd app && flutter build windows      # on Windows: build/windows/x64/runner/Release/RogueOBD2DiagnosticTool.exe
cd app && flutter build apk          # Android APK
cd app && flutter build appbundle    # Android App Bundle
```

CI builds the Windows release folder and the Android APK/AAB on every pull request and uploads them as artifacts.

## Installing (no app store)

The app is distributed directly, not through Google Play or the Microsoft Store, and nothing in the build costs money.

- **Windows:** download the `rogue-obd2-windows-x64` artifact, unzip it and run `RogueOBD2DiagnosticTool.exe`. Keep the whole folder together. The exe is not code-signed, so Windows SmartScreen shows "Windows protected your PC" the first time: choose *More info* then *Run anyway*.
- **Android:** download the `rogue-obd2-android` artifact and copy `app-release.apk` to the phone. Allow "Install unknown apps" for your file manager or browser when Android asks. The AAB is built but not uploaded anywhere.

## Fault-code descriptions

`app/assets/dtc/rogue_generic.json` is generated by `tool/build_dtc_pack.py` (run `python3 tool/build_dtc_pack.py` after editing). All wording is original. Each entry is marked as a *generic interpretation*; manufacturer-specific packs can be added later as *verified* definitions and take priority for that make. The app installs the pack into the encrypted database on first run and again whenever its version changes.

## Testing

Testing uses free tools only: the unit tests, the widget tests and the built-in simulator. No paid hardware or services are needed.

## Simulator

Developer mode (Settings) adds a simulated adapter on the Connect page. Every screen shows a **SIMULATED DATA** banner while it is in use. To test the real Wi-Fi path, run a simulated Wi-Fi adapter:

```sh
cd packages/obd_sim && dart run bin/obd_sim_server.dart lean_bank1 35000
```

and connect the app to `127.0.0.1:35000`.

## Safety

The app is read-only by default. Clearing codes (Mode 04) and Mode 08 need a single-use permit that the engine only issues after the user explicitly confirms, for that vehicle. ECU programming is not implemented.
